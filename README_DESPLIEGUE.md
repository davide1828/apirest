# 🚀 Proyecto de Gestión Multimedia (Películas y Series)

Este repositorio alberga una solución **Full-Stack** profesional para la administración de catálogos audiovisuales.

## 🏗️ Estructura de la Solución (Monorepo)

- **/backend**: API REST robusta construida con **Node.js, Express y MongoDB**.
    - ✅ Generación de seriales automáticos (PEL-XXXX).
    - ✅ Middleware de manejo global de errores.
    - ✅ Validaciones de integridad referencial.
    - ✅ Suite de pruebas con Jest/Supertest.
- **/frontend**: SPA moderna con **React 19, Vite y Bootstrap**.
    - ✅ Diseño ultra-responsivo.
    - ✅ Consumo de API optimizado con Axios.
